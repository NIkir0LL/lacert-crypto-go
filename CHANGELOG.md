# История изменений

## v1.1.5 — 2026-08-02

Защита от повторов больше не замедляется при росте нагрузки.

### Изменено
- Хранилище использованных nonce переведено на схему из двух поколений.
  Прежде при каждой вставке обходилась вся таблица в поисках просроченных
  записей, поэтому стоимость проверки росла вместе с наполнением: 166
  микросекунд при двадцати тысячах записей и 1317 при шестидесяти тысячах.
  Теперь устаревшие записи отбрасываются целым поколением, и стоимость не
  зависит от объёма — около одной микросекунды на любом наполнении.

  Поведение не изменилось: повтор отвергается, запись живёт не меньше половины
  заданного срока.

## v1.0.3 — 2026-07-24

Уточнение описания проверки целостности прошивки.

### Изменено
- В README проверка целостности прошивки больше не привязана к ECDSA P-256.
  Подпись выполняется ключом устройства, поэтому подходит любая из поддержанных
  схем — ECDSA P-256, SLH-DSA или Ed25519.

## v1.0.1 — 2026-07-22

Выпуск с уточнениями документации; код криптоядра не менялся относительно 1.0.0.

## v1.0.0 — 2026-07-22

Первый публичный выпуск. Переиспользуемое криптоядро протокола LACERT на Go:
рукопожатие (ML-KEM-1024 + BLAKE3 + ECDSA), сеансовые ключи, атомарная ротация,
AEAD ChaCha20-Poly1305, защита от повторного воспроизведения.
